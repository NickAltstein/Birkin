## Evaluation Protocol: What We Do and Do Not Do

### What We Do
1. **Defensive Validation Only**: We evaluate the efficacy of Receiptd's fail-closed policy engine and Ed25519 execution receipting specifically as a defense against MCP tool-poisoning attacks.
2. **External, Unmodified Execution**: We clone `mcpvenom` into an isolated research directory (`~/research/mcpvenom`) completely outside the `receiptd` codebase. All test scripts are executed unmodified as published.
3. **Architecture Decoupling**: Receiptd operates strictly external to `mcpvenom`. Interception occurs at the network proxy layer (`bench/mcpvenom/gate_proxy/`) or via a local proxy configuration. Zero lines of `mcpvenom` code are imported, wrapped, or embedded into Receiptd.
4. **Local Isolated Canary**: All evaluations target only the local bundled canary server (`localhost:18080`) within an isolated ephemeral workspace initialized via `infra/init-workspace.sh`.
5. **Independent Audit Ledger**: Only execution receipts (`receipts.jsonl`), proxy decision logs, and raw evaluation matrices generated by our proxy and benchmark runs are retained.

### What We Do NOT Do
1. **No Code Modification**: We do not edit, patch, or alter any file inside the `mcpvenom` repository.
2. **No Vendoring or Copying**: We do not copy, vendor, redistribute, or commit any `mcpvenom` source files, scenario descriptions, or YAML benchmarks into `receiptd`.
3. **No Integration into Larger Work**: Receiptd is an independent standalone tool. `mcpvenom` is not bundled, sublicensed, or distributed with Receiptd.
4. **No Real Agent Registration**: We never register the malicious MCP server in any real development or production environment (including Claude Code, Codex, Cursor, or IDE configurations).
5. **No Public or Production Endpoints**: No traffic is directed to public, third-party, or production hosts.
6. **No Model Training**: The software is never used to train, fine-tune, or distill any AI model or system.
7. **No Publication Without Written Consent**: This evaluation is internal defensive research. No benchmark results, derivative data, or comparative findings will be published externally without explicit written authorization from the authors.
